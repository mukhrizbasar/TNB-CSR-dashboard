# TNB CSR Dashboard

One dashboard for TNB's CSR flagship programmes across five pillars (Environment, Economic Social, Education, Wakalah, Sports): map pins, status pipeline, value by state, payment tracking and photos, with fields and statuses that fit each programme.
Sign in with Google. Hosted on GitHub Pages at https://mukhrizbasar.github.io/TNB-CSR-dashboard/. Programme data lives in Firebase, never in this repository. See [SETUP.md](SETUP.md).
